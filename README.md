# Malajong
## By team SanRokuNana of Code Catalyst club of Swinburne 
Project Malajong is a single-player game that takes the tile-matching fun of Mahjong
and combines it with the run-based progression of a roguelike deckbuilder. Players
will shuffle tiles, utilize passive items (called Artifact), and manipulate hand-scoring
algorithms to defeat increasingly point quotas.
