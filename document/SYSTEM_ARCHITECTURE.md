# 🏗️ MALAJONG — System Architecture & Technical Specifications

> **Target Platform:** Unity 6 (6000.0.10f1+) | **Render Pipeline:** Universal 2D (URP)  
> **Language:** C# 12 (.NET Standard 2.1 / Unity Core)  
> **UI Framework:** Unity UGUI + TextMeshPro (TMP)  
> **Design Patterns:** Model-View-Controller (MVC), ScriptableObject Architecture, Strategy Pattern, Observer Pattern  

---

## 3. Core Class Specifications

### 3.1 `ScoreEngine` (Scoring & Validation Solver)
* **Namespace / Location:** `Assets/Script/Core/ScoreEngine.cs`
* **Type:** `static class`
* **Key Methods:**
  ```csharp
  public static ScoreResult Calculate(Combo combo, List<Tile> fullHand, SuitAffinity affinity, List<Spirit> spirits, GameManager runState);
  public static ScorePreview PreviewScore(List<Tile> selectedTiles, List<Tile> fullHand, SuitAffinity affinity, List<Spirit> spirits, GameManager runState);
  public static FullHandEvaluation EvaluateFullHand(List<Tile> handTiles);
  public static bool IsWinningMahjongHand(List<Tile> tiles);
  public static List<(Combo combo, List<Tile> tiles)> FindPlayableCombos(List<Tile> handTiles);
  ```
* **Recursive Backtracking Solver:** `IsWinningMahjongHand` partitions 14 tiles into 1 pair and 4 valid sets (Chows/Pongs/Kongs) using depth-first recursive search with pruning.

---

### 3.2 `Combo` Hierarchy (Strategy Pattern)
* **Base Class:** `public abstract class Combo`
  - `public string Name { get; }`
  - `public List<Tile> Tiles { get; }`
  - `public abstract int BaseChips { get; }`
  - `public abstract float BaseMult { get; }`
  - `public abstract float AffinityBonus { get; }`
  - `public abstract bool IsValid();`
* **Subclasses:**
  - `Chow`: Validates 3 sequential tiles of identical numbered suit.
  - `Pong`: Validates 3 identical tiles (Rank + Suit).
  - `Kong`: Validates 4 identical tiles (Rank + Suit).
  - `ConcealedKong`: Extends `Kong`; additionally asserts `All(t => t.IsSelfDrawn)`.
  - `Pair`: Validates 2 identical tiles.

---

### 3.3 `Spirit` Hierarchy (Lifecycle Hook Hooks)
* **Base Class:** `public abstract class Spirit`
* **Lifecycle Virtual Hooks:**
  ```csharp
  public virtual void OnComboPlayed(Combo combo, ref int chips, ref float mult, SuitAffinity affinity, GameManager run);
  public virtual void OnTileDrawn(Tile tile, GameManager run);
  public virtual void OnRoundStart(GameManager run);
  public virtual void OnRoundEnd(GameManager run);
  ```

---

### 3.4 `TileUI` (Smooth Interactive Micro-Animations)
* **Location:** `Assets/Script/UI/TileUI.cs`
* **Component Type:** `MonoBehaviour, IPointerEnterHandler, IPointerExitHandler, IPointerClickHandler`
* **Animation Philosophy:** Uses a target-based vertical `Lerp` in `Update()` (`transform.localPosition = Vector3.Lerp(..., currentTarget, Time.unscaledDeltaTime * 15f)`).
* **Critical Design Rule:** **Never** call `transform.SetAsLastSibling()` while childed to a `HorizontalLayoutGroup`, as doing so triggers sibling re-indexing loops that cause mouse hover jitter.

## 4. One-Click Editor Automation Tools

1. **`SceneSetupTool.SetupPlayableScene()`** (Menu: `Malajong/Setup Playable Scene Placeholder`):
   - Wipes and rebuilds the 1920x1080 canvas hierarchy.
   - Binds `TMP_FontAsset` (`m5x7`) across all UI text and buttons.
   - Generates the standard `TilePrefab.prefab` with 70x95px sizing.
   - Binds all button event listeners and connects `UIManager` to `GameManager`.
2. **`MahjongAssetWiringTool.SliceAndWireAllTiles()`** (Menu: `Malajong/Auto-Slice Spritesheet and Wire Tiles`):
   - Configures `deck_mahjong_light_0.png` with pixel-perfect coordinates (46x62 per tile, step 64x64, margin 9px).
   - Generates 34 named sub-sprites and links them to their corresponding `TileData` ScriptableObjects.
3. **`TileDataGenerator.GenerateAllGameData()`**:
   - Creates any missing `TileData`, `SpiritData`, or `BlindData` ScriptableObjects in `Assets/ScriptableObjects/`.
